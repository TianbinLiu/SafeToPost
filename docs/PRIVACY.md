# Privacy notes

The point of the app is to show what a photo and a caption give away before they are posted. That only works if the analysis itself stays local.

## What is processed

- The photo bytes you pick, the EXIF/JPEG metadata inside them, the decoded bitmap, the detected face regions, and the caption text.
- The cleaned image that you export.

## Where it is processed

- Metadata parsing, face detection, blurring, caption scanning, and scoring run **on the device**.
- The test build does not ask for an account or a sign-in.
- The APK declares `INTERNET` and `ACCESS_NETWORK_STATE` (the ML Kit/AndroidX stack commonly pulls these in). The analysis path documented in `ARCHITECTURE.md` does not need a server. If you want a strict guarantee that nothing leaves the phone, run the test build with networking disabled — the core scan/clean/export flow does not depend on it.

## What is kept

- The original photo is never modified. Stripping and blurring produce a new image; the export goes through MediaStore so it lands in the gallery like any other saved picture.
- Face regions and metadata are held in memory for the current scan. They are not uploaded or written to a database.
- The risk score is a heuristic estimate from the visible factors, not a guarantee that a post is safe.

## Permissions

| Permission | Why |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | Declared by the ML Kit/AndroidX dependencies. |
| `app.safetopost.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | Generated by AndroidX for non-exported receivers. |

The app uses the system photo picker / MediaStore APIs, so it does not need broad storage permissions to let you pick a photo or save the cleaned copy.
